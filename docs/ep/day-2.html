一个方程组，两张照片

行图像列图像Ax=b
同一个方程组，站在不同角度看，能「拍」出两张截然不同的照片。
先看一个现象

方程组：x − 2y = 1；3x + 2y = 11。

行图像：把每个方程看成平面上的一条直线。两条线的交点 (3, 2) 就是解——两条路在哪里相遇。

列图像：把两个方程竖着看，变成「列向量怎么组合出 b」：(1,3)·x + (−2,2)·y = (1,11)。

同一件事：行图像问「两条线在哪交叉」，列图像问「两个箭头的什么配比重叠成第三个箭头」。

背后的道理
列图像才是线性代数的母语
Strang 反复强调列图像比行图像重要得多。原因是一旦维度升高，行图像（多个平面相交）就没法画了，但列图像（向量的线性组合）永远成立——它直接通向列空间。
无解还是有解，一眼看出
行图像里两线平行 ⇒ 无解；重合 ⇒ 无穷多解。列图像里 b 落在两个列向量张成的方向上 ⇒ 有解，否则无解。
Ax = b 的两种读法
左读：A 作用在未知的 x 上得到 b（变换视角）。右读：A 的列按 x 的分量加权相加组合出 b（组合视角）。整门课在这两种读法之间来回切换。
方程组
x − 2y = 1, 3x + 2y = 11
解为 (x, y) = (3, 2)。矩阵形式 Ax = b，A = [[1,−2],[3,2]]，b = (1,11)。
冷知识
为什么第一节课不放公式
Strang 用两条直线的交点开场，是先建立几何直觉——公式是用来「固定」直觉的工具，而不是相反。
Strang 原话 “The row picture and the column picture: same equations, two very different ways to see them.” — Gilbert Strang · §2.1 Vectors and Linear Equations
教材出处 Introduction to Linear Algebra (5th) · §2.1 Vectors and Linear Equations pp. 41–44
留一个想头

一个复杂问题，往往也能「拍两张照片」：一张从约束看（行图像），一张从组合看（列图像）。换一张看，卡住的地方经常就通了。
