矩阵是一扇门

列空间零空间子空间
矩阵像一扇门：列空间告诉你走进去能到达哪里，零空间告诉你有多少条路走进去等于没走。
先看一个现象

奶茶店：A 是配方矩阵，x 是「各做几杯」的数量，Ax = 用掉多少原料。

列空间 C(A)：所有可能做出的原料组合——「能到哪」。

零空间 N(A)：哪些配方组合等于白加（Ax = 0）——「白走的路」。

一个管「能到哪」，一个管「走多少步等于没走」。两者刚好互补。

背后的道理
两种造子空间的方式
一种靠「张成」：拿列向量做线性组合，造出列空间。另一种靠「约束」：要求 Ax = 0，解出来的所有 x 构成零空间。张成与约束，是造子空间的两条路。
Ax = b 有解的判据
Ax = b 有解，当且仅当 b 落在 A 的列空间里。这句话把「解方程」翻译成了「b 在不在某个空间里」——一个几何问题。
零空间衡量「信息丢失」
零空间越大，说明 A 压掉的方向越多，可逆性越差。零空间只有零向量 ⇔ 列线性无关 ⇔ 可逆。
列空间
C(A) = { Ax : x ∈ Rⁿ }
A 所有列向量的线性组合构成的集合，是 Rᵐ 的子空间。它决定了哪些 b 有解。
零空间
N(A) = { x : Ax = 0 }
让 A「归零」的所有输入，是 Rⁿ 的子空间（必然包含原点）。
冷知识
「空间」为什么必须过原点
子空间的三个条件：包含零向量、对加法封闭、对数乘封闭。少任何一条，它就只能叫「集合」，不能叫「空间」。
Strang 原话 “The column space is crucial to the whole book… Ax = b is solvable if and only if b is in the column space of A.” — Gilbert Strang · §3.1–3.2
教材出处 Introduction to Linear Algebra (5th) · §3.1 Spaces of Vectors / §3.2 The Nullspace of A pp. 121–140
留一个想头

「能到哪」和「白走的路」——这对概念能套用到很多地方。做一件事，先问它的列空间（能产出什么），再问它的零空间（哪些投入是白费的）。零空间越大，效率越低。
