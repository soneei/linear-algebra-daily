自由变量的人生哲学

零空间自由变量特解
当方程比未知数少的时候，有些变量天生就是自由的。
先看一个现象

侦探案子：3 条线索、4 个嫌疑人。线索不足以给所有人定罪。

必然有 2 个人（自由变量）永远无法被线索确定——他们可以自由取值。

剩下的 2 个（主变量）则被线索绑死：一旦自由变量定了，主变量就跟着定。

把自由变量轮流取 (1,0)、(0,1)，就得到两个「特解」。所有特解的线性组合，张成整个零空间。

背后的道理
自由变量 = 信息的缺口
每少一个独立方程（少一个主元），就多一个自由变量。n − r 个自由变量，意味着零空间有 n − r 维——有 n − r 个「随便走也不改变结果」的方向。
消元不改变零空间
N(A) = N(U) = N(R)：行变换不改变 Ax = 0 的解集。所以可以放心先消元，再回代求特解。
特解张成零空间
每个自由变量对应一个特解（把它取 1、其余自由变量取 0）。这些特解线性无关，正好是零空间的一组基。
零空间的维数
dim N(A) = n − r
n 是列数（未知数个数），r 是秩（主元个数）。自由变量个数 = 零空间维数。
特解构造
自由变量取 (1,0,…), (0,1,…) 后回代
求出对应的主变量，得到一组线性无关的特解，张成 N(A)。
冷知识
零空间为什么是子空间
Ax = 0 的解集自动满足「过原点 + 对加法封闭 + 对数乘封闭」：0 是解；两个解相加还是解；解乘任意数还是解。这就是它能叫「空间」的原因。
Strang 原话 “Elimination does not change the nullspace: N(A) = N(U) = N(R).” — Gilbert Strang · §3.2 The Nullspace of A
教材出处 Introduction to Linear Algebra (5th) · §3.2 The Nullspace of A: Solving Ax = 0 and Rx = 0 pp. 132–140
留一个想头

「自由变量」其实是个很实用的概念：一个系统里，哪些变量你管不着、也不需要管？它们就是自由变量。真正需要锁定的，是主变量——数量等于秩。
