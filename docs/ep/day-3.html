同一个三兄弟，两个截然不同的矩阵

差分矩阵循环矩阵可逆性
同样三个向量 (u, v, w)，放进矩阵 A 能倒推回来，放进矩阵 C 就永远回不来。
先看一个现象

三个人排成一列，相邻两人之差构成一组「差值」输出。

矩阵 A 做的是差分：输出 (v−u, w−v) 两个差值——但这两个差值配合起点就能还原三个原值。

矩阵 C 做的是循环差分：输出 (v−u, w−v, u−w)，多算了一个差值。

怪事：C 比 A 多给一条信息，反而更不能倒推——因为三个差值之和恒等于 0，第三行是前两行的组合，多余却无用。

背后的道理
信息多 ≠ 信息全
C 输出了 3 个数，A 只输出 2 个，但 A 能还原而 C 不能。关键不在数量，而在列向量是否线性无关。C 的三列线性相关（相加为 0），丢掉了一个独立方向。
可逆性的物理直觉
A 像一根固定在墙上的绳子：知道起点就能推出整条绳子。C 像一个闭环：转一圈回到原点，你无法判断从哪出发——力必须平衡（差值总和为 0）才能稳定。
线性无关 → 张成空间 → 有解
这条逻辑链是整门课的主干：列是否线性无关？能张成整个空间吗？Ax = b 对任意 b 有解吗？三个问题其实是同一个问题。
差分矩阵（列独立）
A = [[−1,1,0],[0,−1,1]]
2×3 差分矩阵，行独立。它是「离散导数」，转置对应「离散积分」/累加。
循环矩阵（不可逆）
C = [[−1,1,0],[0,−1,1],[1,0,−1]]
三行相加为 0 ⇒ 行线性相关 ⇒ det C = 0 ⇒ 不可逆。这就是「力必须平衡」的数学表达。
冷知识
导数与积分的矩阵版
差分矩阵 A 会反复出现在 SVD、图论、信号处理里——它就是「离散导数」。而 A 的转置是「累加」。导数与积分互为逆运算，在矩阵世界就是 A 与 Aᵀ 的关系。
Strang 原话 “Linear combinations are the key to linear algebra.” — Gilbert Strang · §1.3 Matrices
教材出处 Introduction to Linear Algebra (5th) · §1.3 Matrices pp. 31–39
留一个想头

「多了一条信息，反而更不可解」这个反直觉现象值得记住。现实里也常见：指标堆得越多，独立维度反而越少，噪声把信号淹了。判据只有一个——它们是不是互相独立。
