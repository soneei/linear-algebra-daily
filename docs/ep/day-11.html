Day 11 · 第一单元 · 2026-06-26

宜家柜子的螺丝，多一颗就废

线性无关基维数
在 2 维空间里塞 3 个独立向量，就像在 4 个抽屉里塞 8 颗螺丝——必然有抽屉要合并。
先看一个现象

宜家的柜子配 8 颗螺丝、4 个孔位——多出来的螺丝无处可拧。

数学里同理：在 Rᵐ 中，任何 m+1 个向量必然线性相关。

反过来，一个空间里「最少且刚好」张成它的那组向量，叫基（basis）。

基里向量的个数，叫维数（dimension）——而且任何一组基，个数都一样。这是定理，不是定义。

背后的道理
维数是被证明出来的
「所有基的向量个数都相等」不是定义，是定理。正因如此，「维数」才可以被定义为基的向量个数。
三副面孔同一张脸
下面三件事互为等价：零空间只有零向量 ⇔ 各列线性无关 ⇔ 满秩 r = n。这是本单元反复出现的主题。
基 = 不冗余也不缺角
基的两个要求：张成整个空间（不缺），且线性无关（不冗余）。少一个向量就张不成，多一个就必然相关。
线性无关
c₁v₁ + c₂v₂ + … + cₙvₙ = 0 仅有零解 c = 0
没有任何一个向量能由其余的线性组合出来。等价于以它们为列的矩阵零空间只有零向量。
维数定理
任何基都含相同个数的向量
个数即空间的维数。Rⁿ 的维数是 n；列空间维数是 r；零空间维数是 n − r。
冷知识
Rᵐ 里最多几个独立向量
最多 m 个，超过必然相关。这解释了为什么「方程多于未知数」时经常无解，也解释了为什么绝大多数 m×n（m > n）矩阵不可逆。
Strang 原话 “All bases for a vector space contain the same number of vectors. The number of vectors, in any and every basis, is the 'dimension' of the space.” — Gilbert Strang · §3.4 Independence, Basis and Dimension
教材出处 Introduction to Linear Algebra (5th) · §3.4 Independence, Basis and Dimension pp. 163–180
留一个想头

「最小且完整」是一对张力。基就是这种平衡的产物：多一个冗余，少一个残缺。想想你手头的信息/指标/资源，哪些是基、哪些是冗余？把冗余拿掉，系统反而更清晰。
