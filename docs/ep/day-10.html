¥30 套餐与一桌免费的菜

通解特解仿射子空间
一份 ¥30 套餐 = 一个特解；桌上的免费小菜 = 零空间。
先看一个现象

餐厅套餐：主食定价 ¥30（锁定你的选择），但免费小菜随便加。

对应 Ax = b：特解 x_p 是「锁定 b 的那一份」，零空间是「加了不影响总额的免费项」。

通解 = 一个特解 + 零空间的任意向量：x = x_p + x_n。

几何上，通解是一个不经过原点的「仿射子空间」——被平移过的空间。

背后的道理
解的结构
通解 = 一个特解 + 零空间的所有向量。特解负责「命中 b」，零空间负责「自由漫步」。
存在性与唯一性分开看
有解 ⇔ b ∈ C(A)（列空间）；唯一解 ⇔ 零空间只有零向量。两个条件互相独立，组合出四种情形。
仿射 ≠ 线性
通解集合不经过原点（除非 b = 0），所以它不是子空间——它是「被平移的子空间」，数学上叫仿射子空间。
通解
x = x_p + x_n
x_p 是 Ax = b 的任一特解，x_n 取遍零空间 N(A)。当 b 不在列空间里时，无解。
冷知识
为什么「特解」要特
特解不唯一（任何满足 Ax = b 的 x 都行），我们只是挑一个方便算的（自由变量取 0）。特解不唯一，但零空间是唯一的。
Strang 原话 “The complete solution to Ax = b is a particular solution plus any vector in the nullspace.” — Gilbert Strang · §3.3 The Complete Solution to Ax = b
教材出处 Introduction to Linear Algebra (5th) · §3.3 The Complete Solution to Ax = b pp. 145–160
留一个想头

「一个特解 + 零空间」这个结构，在生活里处处可见：任何一个「可行方案」都可以再加上若干「不影响结果的动作」。做决策时值得问一句：我加的这些动作，落在零空间里吗？
